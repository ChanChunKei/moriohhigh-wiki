## What are the PC combat and Stand keys?

Use this table as a reference for the **PC prompts visible in Morioh High footage**. The bindings below were read from the game HUD, rather than borrowed from another Roblox game. The action shown can depend on whether a Stand is active, so check your current HUD before assuming the same input always has the same result.

| Input | Action shown in the recorded HUD |
| --- | --- |
| `LMB` | Light attack |
| `RMB` | Stand barrage |
| `F` | Block |
| `Q` | Dash |
| `Ctrl` | Lock |
| `Z` | Withdraw Stand |
| `X` | Stand skill |
| `C` (hold) | Voice |
| `M` | Menu |

**LMB and RMB mean the left and right mouse buttons.** The barrage and withdrawal labels are shown with a Stand active. The frame labels Ctrl only as “Lock”; it does not explain targeting or camera behavior. A voice label does not establish every account’s voice access.

## Which inputs matter when a Stand is out?

The selected frame shows **RMB for a Stand barrage, X for the Stand skill, and Z for withdrawal**. It is a useful distinction between a regular light attack and the actions displayed for an active Stand. It does not establish a complete combo, every skill’s effects, or a particular Stand’s damage.

Check the displayed action after changing the Stand’s state. This page does not turn the active-Stand RMB label into an unconditional rule for every character state, or label Z as a verified summoning command without a corresponding prompt.

## Does the voice prompt mean voice commands always work?

No. The recorded HUD shows a held **C** voice prompt, but the label alone does not establish account eligibility, an accepted command list, or a working microphone. Roblox’s [Voice FAQ](https://en.help.roblox.com/hc/en-us/articles/4405807645972-Voice-FAQ) explains that voice access depends on account eligibility and experience support. Follow the options Roblox actually shows for your account.

An advertised voice feature does not replace the keyboard bindings documented above. This guide does not ask you to provide account information or publish an untested list of spoken Stand commands.
